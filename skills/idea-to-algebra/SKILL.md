# 想法 → 代数

一个形式在被实现之前能判定的部分，往往比实现之后能测的部分更多。本技能把"这个想法新在哪"变成一个 30 秒可验的代数问题。

**核心动作是归约（reduction），不是拟合。** 归约给出精确结论，拟合给出概率结论；先归约，归约不成才拟合。

## 何时用

- 有人提出一个新的打分函数 / 加权 / 距离核 / 门控 / 归一化
- 想知道它是不是 softmax、加权和、或某个已有策略的重参数化
- 要从一批实验数据反推函数形式
- 准备为一个新机制写 kernel、算子、或训练脚本之前

## 结论只有三种形状

| 判据 | 含义 | 下一步 |
|---|---|---|
| **退化** | 可化到已知结构，且额外自由度不改变排序 | 不写代码；写裁决卡 |
| **待定** | 存在低维结构，但不在已有目录内 | 进 L2 |
| **非退化** | 参数匹配控制基打不过它 | 值得实现 |

先把目标定成这三种之一，再动手。没有形状的分析会一直分析下去。

## 阶梯

三级成本差几个数量级，**按顺序走，不要跳级**。

### L0 符号归约｜分钟

把形式写成不带归一化的分子，再让它和分母一起受同一套代数操作。

做法：写出 $w_{ij}=\dfrac{N_{ij}}{\sum_{j'}N_{ij'}}$，对 $N$ 做因式分解，看哪些因子在分子分母同时出现。

**完成判据**：得到一行约化后的表达式，并逐个点出"哪个参数因为约分而消失"。消失的参数是本次分析最值钱的东西——它证明设计文档里关于该参数的所有叙述都不成立。

### L1 数值探针｜分钟

在随机点和真实小样本上测不变量。四条，每条一次运行。

1. **尺度/平移测试**：某因子乘 $c$、某参数在对数域加常数，输出变不变。用来发现 L0 漏掉的抵消。
2. **自由度测试**：能否被"常数 + 单调基 + 每 key 常数"解释；报留出集 $R^2$ 的**增量**（不是绝对值）。
3. **特权测试**：与**同参数量**的控制基比 $\Delta R^2$。这是分支判定的主判据。
4. **稀疏测试**：报有效参与数 $1/\overline{\sum_j w_{ij}^2}$，与稠密基线并列。

**完成判据**：四条都有具体数值，且据此能给三种形状之一一个初步判定，以及主导该判定的那一条。

### L2 规律拟合｜小时到天

**只在 L1 报"待定"或"非退化"时进入。** 归约已经给出结论时进入 L2，是用算力买一个更差估计。

手段：符号回归（PySR 类）、稀疏辨识（SINDy 类）、或带结构约束的参数拟合。

**完成判据**：同时满足三条才认定"发现了公式"——
- (a) 留出集 $R^2$ 高于参数匹配控制基；
- (b) 拟合出的参数可解释（每个参数能指认一个物理/语义量）；
- (c) 换 seed 与换数据切片后形式稳定。

只满足 (a) 是过拟合，不是发现。

### 裁决卡｜十分钟

把上面三步的结果压成一页，交给提出想法的人。模板见 `references/verdict-card.md`。

若结论是"退化"：**必须**补一段"还剩什么"——把约化后残余的差异映射到一个可能有用的小机制。这一步决定这份分析是判决书还是废纸。

## 反模式

每一条都在真实项目里制造过一个自信而错误的结果。

| 症状 | 后果 | 正确做法 |
|---|---|---|
| 只看 $R^2$ 绝对值 | 任何基都能拿到高分 | 与同参数量控制基比 $\Delta R^2$ |
| 用精度差判冗余 | 方差淹没小效应 | 扫初值看系数变化**方向** |
| 宣称稀疏 | 没人核对，结论悬空 | 报有效参与数并与基线并列 |
| 阈值取"当前均值的比例" | 大 N 上级联自毁 | 绝对参照 + 每步限速 |
| 参数零初始化 | 偶函数项梯度恒为零 | 小随机初始化 |
| 单批数据评测 | 记忆伪装成收敛 | 留出批评测 |

## 边界

本技能**不适用**于：形式无法写成闭式（依赖训练动力学、含不可微离散选择）、或唯一可测的是下游性能且无中间量。遇到这类，直接说"不可归约"，别硬套。
