# 裁决卡模板

一页。写完给提出想法的人看，他应该能在两分钟内知道：这个想法还剩什么、要不要写代码。

---

## 裁决卡

**形式**（一行，含归一化与全部参数）

$$w_{ij}=\frac{\dots}{\sum_{j'}\dots}$$

**一句话结论**
> 退化到 ________，额外自由度 ________ 个，其中 ________ 在输出上精确无效。

---

### 证据

| 探针 | 数值 | 说明 |
|---|---|---|
| P1 尺度/平移 | `max|ΔW| = ` | 哪个参数无效 |
| P2 自由度 | `R²(b_j) = ` / `ΔR² = ` | 内容项贡献多少 |
| P3 特权 | `ΔR²(本形式 − 控制基) = ` | 主判据 |
| P4 稀疏 | `eff = ` / `baseline = ` | 稀疏是否存在 |

**判据**：退化 / 待定 / 非退化 —— 主导这一判定的是 P___。

---

### 它还剩下什么

三段，缺一段这张卡就不完整：

1. **精确无效的部分**：哪些参数、哪些叙述可以删除。附实测数值。
2. **残余的有效差异**：约化后仍存在的那一点差别是什么，它在什么条件下变大。
3. **可转化为机制的部分**：把残余差异重新表达成一个**更小、更便宜**的机制，并给出它的验证判据。

第 3 段是这张卡唯一可能改变后续工作的部分。

## 填写示例（参考，不要照抄结论）

**形式**：$w_{ij}=m_im_je^{-\lVert \hat q_i-\hat k_j\rVert^2/2\sigma^2}\big/\sum_{j'}(\cdot)$

**一句话结论**：退化到"softmax + 逐 key 对数偏置 + 余弦重参数化"，额外自由度 2 个，其中查询侧质量 $m_i$ 在输出上精确无效（扰动 $10^2$ 倍，输出变化 $2.4\times10^{-8}$）。

**它还剩下什么**：① 查询侧质量及其全部叙述可删；② 残余差异是余弦的二次项，在相似度分布两端才显现；③ 该残差可用一个逐头曲率系数实现，成本 $O(1)$，判据是它能否在留出集上降低 0.5% 以上的损失。

**边界**：覆盖径向距离核；不覆盖 $f$ 内含行归一化、或半径与质量耦合破坏可分离性的情形。
