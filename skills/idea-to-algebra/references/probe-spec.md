# 探针规格（L1）

四条探针，全部在 CPU 上以分钟级完成。目标不是"证明它有用"，是**给出能一票否决的数值**。

输入约定：
- `score_fn(X, Y) -> L`，`X` 为查询侧特征 $[N,d]$、`Y` 为键侧特征 $[N,d]$，`L` 为 $[N,N]$ logit（未归一化）。
- 若形式含额外参数（质量、半径、温度），把它们作为 `params` 字典传入，探针会逐个做扰动。

---

## P1 尺度/平移测试

**问什么**：某个因子是否在归一化中抵消。

**做法**
- 对每个标量参数 $\theta$，取 $\theta'=\theta\cdot c$（$c\in\{10,100\}$）与 $\theta'=\theta+c$（对数域参数用加法），其余不动，重算 $L$，比较归一化后的权重 $W$。
- 同时做**成对扰动**：只放大查询侧因子，看键侧权重是否随之改变。

**判据**
- $\max|\Delta W| < 10^{-6}$ → 该参数**在输出上无效**。这是最强的一类结论，直接写进裁决卡。
- $\max|\Delta W|\in[10^{-6},10^{-2}]$ → 弱依赖，记录但不作为主证据。
- 否则 → 有效，进入 P2 看它值几个自由度。

**实现要点**：用 `float64` 跑，避免 $10^{-8}$ 噪声被误判成"无效"。阈值取 $10^{-6}$ 是因为 float32 的有效位数只有 $\sim10^{-7}$。

---

## P2 自由度测试

**问什么**：这个形式实际张成了几维函数空间。

**做法**
1. 取目标 $Y_{ij}=\log W_{ij}$，**按行中心化**（去掉 softmax 归一化常数）。行中心化是无损的：$\log w_{ij}=L_{ij}-\log\sum_j e^{L_{ij}}$，减去行均值只丢掉行常数。
2. 构造基：`bias_j`（逐 key 常数，$N$ 个参数）+ 若干内容项。
3. 5 折交叉验证（按**行**切分，不是按元素切分——元素随机切会让同一行的信息泄漏）。
4. 报留出集 $R^2$ 与**增量** $\Delta R^2 = R^2(\text{基})-R^2(b_j)$。

**判据**
- $\Delta R^2 < 0.01$ → 该形式对内容的依赖可以忽略；本质是逐 token 先验。
- 否则记录各基的增量，交给 P3。

**实现要点**：基矩阵每列长度 $N^2$；`bias_j` 列用 `np.tile(np.eye(N)[:,j], N)`，不是 `np.eye(N)[:,j]`（后者长度是 $N$，会静默广播错误）。拟合时该参数数量可以超过样本数，用 `lstsq` 的最小范数解即可，但**必须留出**才能报数。

---

## P3 特权测试（主判据）

**问什么**：它的基是否比"随便一个同参数量的基"更强。

**做法**
- 取 P2 的基，逐项替换为**参数个数相同**的替代基，重新跑同一切分。
- 替代基从与目标同单调性的函数族里选，例如 $\cos^3$、$\cos^5$、阶跃、$\sin$；目标是任意形式时，用同阶多项式与随机特征。

**判据**
- $\Delta R^2(\text{本形式} - \text{控制基}) \le 0.005$ → **无特权**。此时"它抓住了结构"这句话不成立；能抓住的是那一族函数的**共同**形状。
- $> 0.02$ → 有特权，进 L2。
- 中间 → 待定，换第二个数据集再测一次，两次同向才算。

**实现要点**：这是本技能最关键的一条。**参数个数必须严格对齐**，否则比较无意义；控制基要一次给 2–3 个，只给一个容易被单个巧合说服。

---

## P4 稀疏测试

**问什么**：形式宣称的稀疏是否真的存在。

**做法**
- 有效参与数 $\mathrm{eff}=\overline{1/\sum_j w_{ij}^2}$，对每个查询取，再对查询求均值。
- 与**同规模稠密基线**并列：因果注意力下基线是 $(N+1)/2$；非因果是 $N$。
- 若形式声称"淘汰"，再报被淘汰项占比与淘汰后的精度/损失。

**判据**
- $\mathrm{eff}/\mathrm{baseline} > 0.95$ → **没有稀疏**。任何"把稀疏换成算力"的叙述在此终止。
- 若淘汰真实发生，**必须同时**报淘汰机制的自身成本；只报压缩比不报成本的结论不可用。

**实现要点**：软衰减（$e^{-\alpha d}$ 一类）永远不产生真稀疏——它只是把权重变小，分母照常求和。要真稀疏必须硬截断或 top-$k$，而硬截断要处理梯度。

---

## 汇总输出

```
P1 scale_shift:  <param> max|ΔW| = ...
P2 dof:          R2(b_j)=..., ΔR2=<内容项>=...
P3 privilege:    ΔR2(本形式-控制基) = ...
P4 sparsity:     eff=..., baseline=..., ratio=...
verdict:         退化 / 待定 / 非退化      ← 由 P3 主导，P1/P4 可一票否决
```
