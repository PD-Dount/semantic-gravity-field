## A. 注意力 / 打分函数

### A1 乘性吸引 → softmax + 秩一偏置 ★

**形式**：$w_{ij}=\dfrac{m_im_jf(d_{ij})}{\sum_{j'}m_im_{j'}f(d_{ij'})}$

**归约到**：$w_{ij}=\mathrm{softmax}_j\big(\log m_j+g(d_{ij})\big)$，其中 $g=\log f$。

**可引用**：任何"每个单元带质量、交互强度正比于质量乘积"的行归一化注意力，**恒等于**标准 softmax 注意力加一个逐 key 的偏置。查询侧质量 $m_i$ 在归一化中精确消失。

**边界**：要求 $m_i$ 可分离、$f$ 只依赖一个从同一坐标算出的距离、分母是对 $j$ 求和、输出是凸组合。若半径由质量导出（$\sigma_{ij}\propto r_i+r_j$ 且 $r\propto m$），可分离性被破坏，$m_i$ 改走带宽通道存活——此时对 $m_i$ 的扰动**会**改变输出，但改变的仍是同一族的形状。

### A2 常数带宽的引力形式 → 余弦二次型

**形式**：$L_{ij}=\alpha s_{ij}-\kappa\big((1-s_{ij})/\sigma^2\big)^{p/2}+b_j$，$s=\cos\theta$，$\sigma$ 与 $p$ 恒定。

**归约到**：$L_{ij}=b_j+\alpha' s_{ij}+\beta' s_{ij}^2+c$。因为 $d^2=2-2s$，幂次展开后只剩 $s$ 的一次与二次项。

**可引用**：恒定带宽下，引力形式的全部内容 = 一个 key 偏置 + 一个余弦斜率 + 一个曲率，共三个自由度。

### A3 三同轴高斯场 → 单个高斯场

**形式**：$\prod_k\exp\!\big(-d^2/2\sigma_k^2\big)$

**归约到**：$\exp\!\big(-d^2/2\sigma_{\rm eff}^2\big)$，$\sigma_{\rm eff}^{-2}=\sum_k\sigma_k^{-2}$。

**可引用**：共享坐标系的多个距离衰减场，其乘积是单个场。要做成多个独立机制，必须给它们不同的度标（不同的度规张量或不同子空间）。

### A4 核注意力 → 线性注意力

**形式**：$w_{ij}=k(q_i,k_j)/\sum_j k(q_i,k_j)$，$k$ 可分解为 $k(a,b)\approx\phi(a)^\top\phi(b)$。

**归约到**：$\mathrm{out}_i=\phi(q_i)^\top\big(\sum_j\phi(k_j)v_j^\top\big)$，复杂度从 $O(N^2d)$ 降到 $O(Nd^2)$。

**可引用**：RBF/高斯核注意力属于这一族，可线性化；因此"距离核"本身不构成计算优势的来源，优势来自特征维度 $d_\phi$ 与序列长度的关系。

## B. 缓存 / 记忆

### B1 质量衰减驱逐 → LRFU

**形式**：$m_j\leftarrow \lambda m_j+1$（命中时），驱逐 $\arg\min_j m_j$。

**归约到**：LRFU（Lee et al., 2001），LRU↔LFU 的连续谱，$\lambda$ 即谱参数。

**可引用**：任何"重要性按衰减累积、驱逐最轻者"的记忆规则都是 LRFU。$\lambda\to0$ 退化为 LRU，$\lambda\to1$ 退化为 LFU。

### B2 无度量的捕获半径 → 零贡献

**形式**：$\log m_j-\kappa(d^2/2\sigma_j^2)^{p/2}$，其中库内没有距离度量（$d$ 恒定）。

**归约到**：$\log m_j$ 的单调变换——排序完全由质量决定，半径项对排序贡献精确为零。

**可引用**：在没有度量的存储里，"捕获半径"不起作用；要让它起作用必须引入内容距离，而那时形式立刻变成"相关 + 近期 + 重要"的可加打分。

## C. 推理范式

### C1 迭代自注意力 → 聚簇动力学

**形式**：$x^{(t+1)}=\mathrm{norm}\big(x^{(t)}+\lambda(W^{(t)}x^{(t)}-x^{(t)})\big)$

**归约到**：球面上的相互作用粒子系统；已知结论是 token 随迭代聚簇（Geshkovski et al., 2025）。

**可引用**：迭代注意力本身就会产生聚类，因此"观察到聚类"不能作为任何新机制的证据，除非有对照臂证明对照组**不**聚簇。

### C2 全局吸引且无排斥 → 必然坍缩

**形式**：只有吸引项的行随机（row-stochastic）动力学。

**归约到**：均匀化/共识动力学。每行向全局加权均值漂移，$N$ 越大漂得越均匀。

**可引用**：只有吸引、没有竞争或截断的场，在足够迭代步后必然收敛到单点。要稳定多簇，必须引入排斥、负载均衡或硬截断中的至少一个。
